# 🛡️ Network Intrusion Detection using Big Data Visualization

This project focuses on **detecting network intrusions** through data-driven insights using **PySpark** for large-scale data processing and **Tableau** for visual analytics.  
It aims to identify malicious network activity patterns and classify them based on traffic characteristics to strengthen cybersecurity monitoring.

---

## 📊 Project Overview

With the exponential growth of digital communication, **network intrusion detection** has become essential to safeguard systems from cyber threats.  
This project leverages **Big Data frameworks** to process large volumes of network traffic and visualize attack patterns.

**Key Objectives:**
- Analyze real-world network traffic datasets.
- Identify abnormal or potentially malicious traffic patterns.
- Build scalable preprocessing and analytical pipelines using PySpark.
- Visualize findings in Tableau dashboards for intuitive insights.
